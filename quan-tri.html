Khu vực quản trị

Nhập mật khẩu quản trị để chỉnh sửa giá & ảnh sản phẩm.

Sửa xong bấm “Xuất file cập nhật” để tải san-pham.js mới, rồi đưa lên web (đẩy GitHub hoặc gửi trợ lý).

Cách đưa thay đổi lên web

  1. Bấm “Xuất file cập nhật” → máy tải về file san-pham.js.
  2. Nếu có đổi/thêm ảnh: chép ảnh vào thư mục anh/ (ghi đúng tên đã điền ở ô Ảnh).
  3. Thay file san-pham.js cũ bằng file mới (và ảnh) rồi đẩy lên GitHub — hoặc gửi cả cho trợ lý để cập nhật giúp. Sau ~1 phút web sẽ hiện giá mới cho mọi người.
